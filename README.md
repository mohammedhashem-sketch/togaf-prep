# TOGAF 10 Foundation — Exam Prep

Interactive flashcard app for the OGEA-101 exam. ~235 questions across:

- ADM Phases & Phase-Artifact Drill (with tricky same-format choices)
- Core Concepts, Definitions, Governance
- Enterprise Continuum, Repository, Reference Models
- Content Framework, Views & Viewpoints

Includes an ADM Reference modal with the full ADM Cycle, Enterprise Continuum,
and Architecture Repository diagrams + a complete phase-outputs cheat sheet.
